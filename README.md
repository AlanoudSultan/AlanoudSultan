# AI Research 🔬

## SPAF: Enhanced YOLOv26 for Multi-scale UAV Object Detection

### Computer Vision Research

- Designed and developed a YOLOv26-based object detection model (SPAF) for small-object UAV detection
- Proposed and integrated:
  - Sparse Vision Attention (SVA)
  - Progressive Bidirectional Auxiliary Pyramid Network (PBAP-Net)
  - Adaptive Channel Multi-scale Fusion Head (ACMF)
- Achieved:
  - +7.5% improvement in mAP@0.5 (46.8%)
  - Improved small-object detection on VisDrone2019
- Built and trained the model using:
  - PyTorch
  - Ultralytics Framework
- Conducted:
  - Full pipeline design
  - Ablation studies
  - Performance evaluation
